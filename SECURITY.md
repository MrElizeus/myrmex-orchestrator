# Security policy

Please do not publish credentials, tokens, private keys, browser profiles, or
sensitive repository data in issues or pull requests. For a suspected
vulnerability, contact the repository maintainer privately before disclosure.

See the security model in docs/SECURITY.md for trust boundaries, browser
transport constraints, agent permissions, and delivery protections. Myrmex is
alpha software and should not be used with production secrets without an
appropriate operating-system and account boundary.
